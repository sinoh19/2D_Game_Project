# 인게임 폰트

전체 인게임 텍스트는 프로젝트에 포함된 `Galmuri11.ttf`를 사용합니다.
갈무리11의 권장 크기인 내부 해상도 기준 12px와 정수 배율인 24px를 사용하고,
완성된 640×360 화면을 최근접 보간으로 확대합니다.

- 일반 UI·보조 정보: 12px
- 제목·대사: 24px
- 공식 배포처: https://github.com/quiple/galmuri
- 라이선스: SIL Open Font License 1.1 (`Galmuri-LICENSE.txt`)

폰트 원본은 수정하지 않았으며, 운영체제에 따로 설치할 필요가 없습니다.
