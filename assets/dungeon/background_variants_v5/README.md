# 타일별 기본 색상 편차 보정 v5

내장 image_gen으로 색 균형 방향을 확인한 뒤, 런타임 에셋은 v4 원본에 타일별 고정 RGB 오프셋만 적용했습니다. 내부 픽셀의 상대 명암·줄눈·균열·경계 모양은 그대로이고 이끼/황토색은 원래 색을 보존합니다. 팔레트 압축·블러·그림 재배치는 하지 않았습니다. 각 타일의 동일 표면 표본을 RGB(90,100,106)에 맞췄고, 반올림 오차는 채널당 최대 0.5입니다. 모든 비이끼 픽셀의 일정 RGB 차이와 클리핑 0을 확인했습니다. 자세한 수치는 verification.json에 기록했습니다.
