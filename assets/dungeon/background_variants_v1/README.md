# 던전 배경 에셋 시안 v1

사용자 참고 사진을 내장 image_gen으로 재구성한 에셋입니다. 원본 사진의 픽셀을 그대로 분리한 무손실 추출본은 아닙니다.

| 종류 | 수량 | 개별 캔버스 | 용도 |
|---|---:|---|---|
| intact | 8 | 64×64 | 정상 벽 변형. 32px 그리드 2×2칸 |
| broken | 6 | 128×96 | 불규칙한 구멍이 있는 벽 패널. 32px 그리드 4×3칸 |
| windows | 6 | 48×80 | 온전한/파손된 아치 창문, 고딕 창문, 작은 철창 시안 |

모두 640×360 게임 화면에서 1:1로 배치할 네이티브 PNG입니다. 미리보기만 정수 배율로 확대했습니다.

## 배치

- 정상 벽은 하나만 반복하지 말고 변형을 섞습니다. `.tsx`에는 기본 랜덤 가중치가 들어 있습니다.
- 파손 벽은 반복 무늬로 도배하지 않고 방마다 크기·위치·형태를 골라 드물게 배치합니다. 다섯 번째는 두 개의 별도 구멍입니다.
- 구멍은 실제 알파 0입니다. 구멍 뒤로 보일 하늘/원경을 먼저 그리고, 해당 영역의 정상 벽을 파손 패널로 교체합니다. 정상 벽 위에 단순히 겹치면 뒤의 정상 벽이 그대로 보입니다.
- 미리보기 파손 벽의 청록색은 확인용 배경이며 PNG의 구멍 색이 아닙니다.
- 창문 바깥은 투명하고 안쪽 청록색은 창문 자체의 색입니다. 배경 벽 위에 별도 오브젝트로 배치합니다.
- `.tsx`는 각 종류를 해당 패널 크기로 선택하는 Tiled 시트입니다. 게임의 32px 기본 그리드에서 큰 패널/창문은 오브젝트 레이어에 배치할 수 있습니다.
- 서로 다른 셀의 경계가 완벽한 Wang 자동 연결 세트로 검증된 것은 아닙니다. 현재 게임 맵에는 적용하지 않은 검토용 에셋 팩입니다.

## 파일

`intact/`, `broken/`, `windows/`: 개별 PNG 20개. `*-atlas.png`: 종류별 시트 3장.
`overview.png`: 전체 미리보기. `manifest.json`: 크기·파일 해시. `prompts.json`: 실제 생성·수정 프롬프트.

투명도와 파일 크기를 확인했습니다. 생성 결과에 그려진 흰 체커 오류는 PNG 출력 단계에서 알파 0으로 정리했고, 창문 알파도 경계가 흐려지지 않도록 정리했습니다. 새 그림을 코드로 대신 그리지는 않았습니다.
