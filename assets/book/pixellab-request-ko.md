# PixelLab에 전달한 책 펼침 요구사항

1. 큰 도트의 붉은 일기장이 나무 책상 오른쪽에 놓여 있다.
2. 책상, 책등의 축, 오른쪽 종이 묶음의 위치와 크기는 고정한다.
3. 앞표지가 위로 들려 비스듬한 모서리·두께·그림자가 보인다.
4. 책등 위에서 얇은 옆면이 보이는 순간을 거쳐 왼쪽으로 넘어가 펼쳐진다.
5. 옆으로 밀거나 가로로 늘이고 줄이는 느낌을 피한다.
6. 끝은 제공한 펼친 책 이미지와 일치시킨다.
7. 두 페이지의 검은색 읽을 수 없는 필기 자국을 유지한다.
8. 왼쪽 바깥의 불필요한 제본 띠는 제외하고 모서리 장식은 실제 모서리에만 둔다.
9. 부스러기, 떨어진 종잇조각, 떠다니는 점, 손이나 새 소품은 추가하지 않는다.

시작 이미지: `closed-input.png`. 끝 이미지: `open-input.png`.
사용 도구: PixelLab PixMiniMax, 32프레임, 불투명 배경, 프롬프트 자동 확장 끔.
원문 영어 프롬프트: `prompt.txt`.
