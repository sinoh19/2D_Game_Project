# 배경 배치

640×360 기준, 네 구간으로 구성한 2560×360 횡스크롤 던전.
- 정상 벽: 64×64 변형 8종, 240칸. 좌우·위아래가 같은 변형이 되지 않도록 고정 시드로 선택.
- 파손 벽: 128×96 패널 8곳, 여섯 가지 구멍 형태를 위치·높이를 달리해 배치.
- 창문: 8곳. 1·4·6번만 사용. 2·3·5번은 로딩·배치에서 제외.
- 원경을 먼저 그리고, 파손 패널 영역에서 정상 벽을 지워 알파 구멍이 실제로 드러나도록 처리.
- 정적 배경은 최초 1회 레이어로 만들고 카메라에 보이는 영역만 그린다. 프레임마다 랜덤 패턴을 다시 만들지 않는다.
- 기존 문·조명·기사 갑옷, 캐릭터, 발판·계단·장애물 충돌 유지.

구간: 던전 입구 → 무너진 회랑 → 기사의 전당 → 봉인된 문.
배치 데이터: assets/dungeon/dungeon_01.json의 background.
