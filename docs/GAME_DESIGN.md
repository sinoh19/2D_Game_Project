# 용병 일기 기획 메모

## 콘셉트

귀족의 의뢰를 받은 용병이 아무도 탐험하지 않은 미지의 던전에 도전한다.
필드 이동·투사체 회피와 거리 기반 턴제 전투를 결합한다.

## 전투 흐름

1. 필드에서 직접 캐릭터를 조종하고 날아오는 투사체를 피한다.
2. 원거리에서 피격되면 먼저 피해를 받고 전투에 진입하며, 플레이어가 먼저 행동한다.
3. 접근 단계에서는 플레이어가 회피 방향, 적 AI가 공격 방향을 선택한다. 플레이어는 한 번 행동할 때마다 한 칸 전진한다. 예를 들어 거리가 3칸이면 3턴에 걸쳐 접근한다.
4. 투사체를 모두 피하고 가까이에서 공격해 시작하면 플레이어가 선공한다.
5. 근접전은 플레이어와 적이 번갈아 공격·방어한다. 상단/중단/하단 공격과 방어의 일치 여부로 피해를 판정한다. 피해 반감 또는 무효화의 수치는 추후 확정한다.

## 적 특성 예시

- 리치: 근접 선제 공격으로 진입하면 적에게 2배 피해, 원거리 피격 진입 시 플레이어가 2배 피해.
- 슬라임: 공격 피격 시 중첩 가능한 독.
- 해골 기사: 적 지능에 따라 플레이어의 아이템 사용을 인지하며, 이를 감지하면 분노하여 특수 페이즈 진입.

## 다음 개발 순서

1. 개발용 이동 마커를 확정 캐릭터 애니메이션으로 교체하고 던전 맵을 만든다.
2. 필드 충돌과 투사체 회피·피격을 구현한다.
3. 접근 3칸과 공격/회피 방향 선택 상태를 추가한다.
4. 근접 공격/방어 턴과 피해 판정을 구현한다.
5. 적 특성, 아이템, 지능·특수 페이즈를 연결한다.

현재 코드는 메인 화면과 이동 기반까지만 구현되어 있다. 이 문서의 전투와 적 특성은 다음 구현 범위다.
