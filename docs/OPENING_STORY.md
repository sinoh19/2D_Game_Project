# 오프닝 구성

## 이야기

아이가 책장에서 낡은 일기장을 발견하고 어머니에게 묻는다.
어머니는 자신의 아버지, 즉 아이의 **외할아버지**가 남긴 일기라고 알려준다.
외할아버지가 게임의 주인공인 용병이다.
일기 중 귀족의 의뢰로 미지의 던전을 탐험한 부분이 실제 게임 플레이로 이어진다.

## 순서

1. 게임 시작을 누르면 메인 UI가 사라지고 오두막 가운데 창문으로 천천히 줌인한다.
2. 줌인 마지막 부분에서 화면이 완전히 검어진다.
3. 검은 화면 위 글씨만으로 아이와 어머니의 대화를 진행한다. 인물 이미지는 사용하지 않는다.
4. 대화가 끝나면 덮인 일기장 이미지를 보여준다.
5. 책이 펼쳐지며 일기 속 용병의 던전 탐험으로 넘어간다.

## 현재 구현: 줌인·암전과 검은 화면 대화

- `게임 시작` → `OpeningScene`.
- 메인 화면의 현재 애니메이션 프레임에서 이어지며 UI는 그리지 않는다.
- 가운데 창문 `(270, 280)`을 목표로 약 4.2초 동안 부드럽게 12배까지 확대한다.
- 마지막 1초에 검은 오버레이가 점점 진해지고 최종 화면은 완전한 검정이다.
- 암전 뒤 0.35초 후 아이와 엄마의 대화가 시작된다.
- 8개 대사는 `data/opening_dialogue.json`에 저장하며 초당 22글자로 표시한다.
- 클릭/SPACE: 표시 중에는 현재 문장을 완성하고, 완성 후에는 다음 대사로 넘어간다. 자동 진행은 없다.
- 긴 대사는 실제 폰트 너비로 줄바꿈하며 타이핑 중 줄 배치가 바뀌지 않는다.
- 마지막 대사를 확인하면 오른쪽에 놓인 닫힌 책이 0.45초 동안 나타난다.
- 0.75초 동안 닫힌 책을 보여준 뒤 두 번째 PixelLab 생성본인 33프레임(12fps)의 펼침 애니메이션을 한 번 재생한다.
- 책을 펼치는 동작의 35% 지점부터 16×9 타일 전환이 겹친다. 타일이 뒤집히는 중에도 책 애니메이션은 계속 재생된다.
- 완전 암전을 0.3초 유지하고 타일이 다시 뒤집히며 횡스크롤 던전을 드러낸다.
- 전환은 약 2.7초이며 완료 후 좌우 방향키로 이동하고 스페이스바로 점프, C키로 공격할 수 있다. 전환 중 `ESC`는 메인 화면으로 돌아간다.
- 배경 애니메이션을 꺼도 카메라 전환과 암전은 정상 진행한다.

대화 → 책 펼침 → 타일 암전 → 횡스크롤 던전 연결까지 구현했다. 기존 에셋으로 던전과 캐릭터를 구현했다. 적·투사체와 별도 턴제 전투는 다음 단계다.

## 조정 위치

`game/config.py`의 `OPENING_WINDOW`, `OPENING_DURATION`, `OPENING_FADE_START`, `OPENING_MAX_ZOOM`에서 창문 위치, 전환 시간, 암전 시작 시점, 확대 배율을 변경한다.

현재 책 에셋은 사용자 선택에 따라 검은 필기가 있는 두 번째 PixelLab 버전을 임시 사용한다.

전체 화면과 UI는 docs/ART_STANDARD.md의 640×360 네이티브 기준을 사용하며, 실행 창은 정수 2배인 1280×720이다.
