# 휘장용 배경 돌기둥

큰 파노라마 배경 앞에 세우는 장식 기둥입니다. 기존 바닥·천장의 회청색 암석과 같은 팔레트, 2×2 픽셀 단위로 정리했습니다. 기둥 앞에 휘장·선반을 겹치면 큰 배경 그림 자체를 수정하지 않고도 소품을 걸 공간을 만들 수 있습니다.

## Tiled 사용

기본 맵과 새 맵 템플릿에 **배경 돌기둥** 팔레트와 **배경 기둥** 오브젝트 레이어를 추가했습니다. 이 레이어는 큰 배경 바로 위, 지형·다른 소품 아래에 있어 연결부가 기존 지형에 가려지고 휘장이 앞에 표시됩니다. 충돌은 없습니다.

- 한 번에 배치: 완성형 **64×288**을 타일 삽입 도구로 놓습니다. 천장 타일 윗변 Y=0, 바닥 윗면 Y=288인 곳에서는 기둥 오브젝트 Y=288로 맞추면 됩니다. 윗 연결부가 천장 안쪽에 겹쳐 울퉁불퉁한 끝선과의 틈을 가립니다.
- 높이 조절: 천장 연결 **64×32** → 중간 A/B **64×32** 여러 개 → 바닥 연결 **64×32** 순으로 세로 배치합니다. 같은 X를 사용하고 각 오브젝트 Y를32씩 늘리세요. 중간 A/B는 연결 경계가 같아서 섞어 사용할 수 있습니다.
- 돌기둥 폭64, 휘장 폭24 기준으로 휘장의 X를 `기둥 X + 20`에 두면 중앙에 걸립니다. 휘장은 **횃불·갑옷** 같은 앞쪽 오브젝트 레이어에 놓습니다. 휘장과 기둥을 모두 같은 레이어에 놓을 때는 기둥을 먼저, 휘장을 나중에 놓습니다.
- 천장/바닥과 조금 겹쳐도 지형이 앞에 그려져 자연스럽게 가려집니다. 완성형의 세로를 늘려 늘어뜨리기보다 중간 조각 수로 높이를 맞추세요.

이미지는 `maps/tilesets/images/pillars/`에 있습니다. Tiled에서 팔레트가 갱신되지 않으면 맵을 저장하고 다시 여세요. 게임은 F6으로 다시 읽을 수 있습니다.
