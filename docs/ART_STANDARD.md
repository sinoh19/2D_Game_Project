# 640×360 아트 기준

## 공통

모든 화면을 640×360 네이티브 렌더 타깃에서 완성한 뒤 정수 2배인 1280×720으로 표시한다. 화면과 개별 스프라이트의 캔버스 크기는 구분한다.

| 종류 | 네이티브 규격 |
|---|---|
| 전체 화면·메인 배경 프레임·책 프레임 | 640×360 |
| 캐릭터 대기·이동·점프 프레임 | 56×56 |
| 공격 프레임 | 112×112 (검 동작 여백 포함) |
| 지형 타일 | 32×32 |
| 대문 | 94×117 |
| 기사 갑옷 장식 | 38×76 |
| 조명 몸체 | 33×64 |
| 불꽃 | 11×11, 6프레임 |
| 대사 본문 | 글꼴 크기 18 |

캐릭터는 검과 투명 여백을 제외한 머리~발 높이 약 46px, 화면 높이의 약 12.8%를 기준으로 한다. 공격 중 검을 포함한 전체 경계는 더 커질 수 있다.

## 변환·보존

- 기존 원본은 삭제하지 않는다. 변환은 영역 추출과 최근접 크기 정리로만 수행하며 AI로 다시 그리지 않았다.
- 타일의 좌우/상하 반전, 소품의 피벗, 캐릭터의 프레임 순서와 재생 시간은 유지한다. 크기에 맞춰 피벗을 정수 픽셀로 맞췄다.
- 메인/책의 저해상도 원본을 확대해도 디테일이 새로 생기지는 않는다. 기존 큰 픽셀 모양을 유지한 640×360 프레임이다.
- 변환 파일별 원본, 추출 영역, 출력 크기, 원본/결과 해시는 `assets/native640-manifest.json`에 기록한다.
- 유니티 원본 참조는 `assets/dungeon/approved-import.json`, 원본 파일 출처는 `assets/dungeon/sources.json`에 보관한다. 네이티브 런타임 파일은 변환 기록을 따른다.

## 이후 제작

새 타일은 32×32 규격과 현재 색감·도트 밀도에 맞추고, 소품은 캐릭터와 같은 640×360 장면에서 크기를 확인한다. 작업물마다 임의의 화면 확대 배율을 추가하지 않는다. 투명 여백이 아닌 실제 그림의 크기로 비교한다.
