# 사진 기반 던전 소품

10종을 내장 이미지 도구로 개별 추출·재구성한 뒤, 공용 24색 팔레트와 2×2 픽셀 격자로 정리했습니다. 배경·바닥·외부 그림자를 제거한 투명 PNG입니다. 기존 승인 에셋은 교체하지 않습니다.

## Tiled 배치

기본 맵과 새 맵 템플릿에 **가구·소품**, **목재 구조물** 팔레트를 연결했습니다. 다른 맵에는 `maps/tilesets/furniture.tsj`, `maps/tilesets/wood-structures.tsj`를 외부 타일셋으로 추가합니다.

오브젝트 레이어를 선택하고 팔레트에서 그림을 고른 뒤 **타일 삽입(Insert Tile)** 도구로 배치합니다. 기본 기준점은 왼쪽 아래입니다. 바닥 가구의 Y를 지형 윗면에 맞추면 됩니다. 휘장·선반처럼 벽에 거는 소품은 원하는 위치에 놓습니다. 새로 들어간 소품은 장식 이미지이며, 충돌·수납·상자 열기·계단 이동 판정은 포함하지 않습니다.

## 목재 구조를 구분한 기준

- 나무 계단: 사진 1의 수직 통로 아래쪽에 내려가는 구조. 짧은 판자 네 장과 가는 세로 연결재로 만들고, 계단 아래와 발판 사이를 투명하게 남겼습니다. 돌계단이나 속이 찬 나무 경사면으로 바꾸지 않았습니다. 필요하면 Tiled에서 수평 뒤집기로 반대 방향으로 배치합니다.
- 나무 다리: 사진 1의 바닥 구멍 위를 잇는 구조. 수평 판자 상판과 양끝 아래의 대각선 버팀대이며, 난간·밧줄·돌 받침은 포함하지 않습니다.
- 보물상자: 잠금쇠와 금속 띠가 있는 뚜껑형 상자. 박스는 세로 널빤지가 있는 사각 목재 상자로 분리했습니다.

원본 사진은 배경과 조명에 의해 색이 달라지므로 최종 도트의 색은 프로젝트 공용 팔레트로 맞췄습니다. 목재와 천·뼈의 재질은 밝기와 실루엣으로 구분합니다.
