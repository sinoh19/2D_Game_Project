# Tiled로 맵 만들기

## 열기와 실행

1. 게임 폴더의 **open_map.cmd**를 실행합니다. 준비된 Tiled 편집기에서 현재 맵과 팔레트를 엽니다. 편집기가 없는 PC에서는 공식 배포를 `.tools`에 준비합니다.
2. 게임은 **run_game.cmd**로 실행합니다. 오른쪽 위 **디버그: 인게임**으로 바로 진입할 수 있습니다.
3. Tiled에서 수정한 뒤 **Ctrl+S**로 저장하고, 실행 중인 게임에서 **F6**을 누릅니다. 위치와 열린 문 상태를 유지하며 맵을 다시 읽습니다. 잘못된 맵은 기존 화면을 유지하고 오류를 표시합니다.

기본 편집 파일은 `maps/dungeon_01.tmj`, 편집기 프로젝트는 `maps/mercenary.tiled-project`입니다. 자체 형식 `assets/dungeon/dungeon_01.json`은 에셋·애니메이션 라이브러리와 과거 맵 보관용이며, 현재 배치는 `.tmj`에서 읽습니다.

## 타일 칠하기

오른쪽 타일셋에서 **동굴 지형 32px**를 고른 뒤, 레이어에서 **새 지형 (자동 충돌)**을 선택합니다. 스탬프 브러시로 칠하고 지우개로 지웁니다. 이 레이어에 새로 놓은 바닥·벽·천장은 자동 충돌을 사용합니다. 계단 반쪽 타일 두 개는 대각선 경사 판정을 갖고 있어 한 쌍으로 놓으면 64×32 경사가 됩니다. 자동 충돌 경사 타일은 수평 뒤집기만 지원합니다.

완성된 팔레트에는 바닥, 내부 채움, 천장 3종, 상승/하강 계단 4개, 좌우 벽과 하단 모서리가 들어 있습니다. 이미지 생성 도구로 그리는 과정 없이 준비된 타일을 선택해 배치하면 됩니다.

## 기존 맵 레이어

| 레이어 | 편집 방법 |
|---|---|
| 배경 이미지 | 큰 던전 이미지 한 장. 기본 잠금. 파일을 바꾸면 게임에서 읽고 맵 너비에 맞춰 패럴랙스를 계산 |
| 횃불·갑옷 | 오브젝트 선택 도구로 이동·복사. 가로세로 비율 유지. 게임에서는 불꽃 애니메이션 재생 |
| 기존 지형 32px | 일반 격자의 기존 타일. 브러시·지우개로 수정 |
| 기존 지형 16px 보정 | 원래 16픽셀 어긋난 위치의 타일을 보존하는 레이어. 격자 기준점이 16픽셀 이동 |
| 기존 세밀 배치 | 부분 너비 바닥 등 7개 타일 오브젝트. 선택해서 이동·크기 조절 |
| 발판 | 짧은/긴 발판을 선택·이동·복사. 그림과 위에서만 밟는 판정이 함께 이동 |
| 새 지형 (자동 충돌) | 새로 칠할 때 권장. 타일 자체의 충돌 자동 사용 |
| 기존 충돌·발판 | 원래 맵의 사각 충돌. 눈 아이콘을 켜면 붉은 사각형으로 편집 가능 |
| 대각선 경사면 | 원래 두 경사면의 선 끝점을 이동. 눈 아이콘을 켜서 편집 |
| 좌우 철문 통로 | 통로 전체를 선택해서 이동. 기존 철창·벽·천장이 함께 이동 |
| 시작 위치 | 노란 시작점. 캐릭터의 발 좌표 |

**기존 지형 레이어와 기존 충돌은 원래 배치를 보존하기 위해 분리했습니다.** 기존 바닥을 옮기거나 지우면 해당 사각 충돌·경사 선도 같이 수정해야 합니다. 기존 지형 레이어의 `autoCollision`을 무작정 켜면 원래 충돌과 중복됩니다. 새 맵은 아래의 자동 충돌 템플릿으로 만드는 편이 간단합니다.

충돌 레이어의 눈 아이콘은 편집기 안내선 표시용입니다. 레이어를 숨겨도 충돌은 게임에 적용됩니다. 실제로 끄려면 해당 레이어나 오브젝트에 bool 속성 `enabled=false`를 지정합니다.

## 장식과 철문 넣기

**장식·통로** 타일셋의 횃불·갑옷·좌측 통로·우측 통로를 오브젝트 레이어에서 타일 오브젝트로 삽입합니다. 짧은/긴 발판은 별도의 **발판** 타일셋에 있습니다. 기존 오브젝트를 복사해서 놓아도 됩니다. 시작 위치와 경사 같은 판정은 타일이 아닌 점/선 오브젝트입니다.

- `Torch`, `Armor`: 게임에서 원래 소품으로 표시하며 횃불이 움직입니다. 회전·뒤집기 없이 가로세로 비율을 유지하세요.
- `Passage`: 폭은 32의 배수로 유지합니다. `side`는 left/right, `openingHeight`는 입구 높이, `gateWidth`는 철문 폭입니다. 높이는 오브젝트 바닥에서 위로 계산합니다.
- 기존 철문을 복사했다면 `gateId`를 새 고유 값으로 바꾸거나 비우세요. 비우면 Tiled 오브젝트 ID를 사용합니다. ID가 중복되면 오류로 알려줍니다.
- `Spawn`: 시작점은 정확히 하나 있어야 합니다.
- `Solid`: 사각형 전체가 막힙니다. `Platform`: 아래에서 점프로 통과할 수 있는 발판입니다.
- `Slope`: 폴리라인으로 대각선을 그리고 클래스를 지정합니다. 수직 선과 오브젝트 회전 대신 끝점을 움직여 편집합니다.

현재 통로는 철문 개방과 통과까지 연결되어 있으며, 다른 맵으로의 전환은 아직 구현하지 않았습니다.

## 새 맵 만들기

`maps/new_level_template.tmj`를 Tiled에서 열고 **다른 이름으로 저장**합니다. 이 템플릿은 자동 충돌 바닥과 시작점만 있는 빈 맵입니다. 기본 맵의 수동 충돌을 지울 필요가 없습니다.

새 맵 실행 예:

```powershell
.\run_game.cmd --map maps/my_dungeon.tmj
```

기본 실행 맵을 영구적으로 바꾸려면 `game/config.py`의 `DEFAULT_TILED_MAP` 경로를 바꿉니다. 기본 게임 화면은 640×360, 타일은 32×32입니다. 맵 너비는 Tiled의 맵 크기 변경으로 늘릴 수 있습니다. 세로 스크롤은 아직 없으므로 `worldHeight=360`을 유지하세요. 타일 행은 12행(384픽셀)이지만 하단 24픽셀은 화면 밖입니다.

맵은 고정 크기 직교 맵, JSON `.tmj`, 외부 JSON 타일셋 `.tsj`를 사용합니다. CSV 배열 또는 비압축/base64 zlib/gzip 데이터를 읽습니다. 무한 맵과 zstd 압축은 사용하지 마세요. 원본 이미지와 타일셋 파일도 같이 Git으로 관리합니다.

.\.venv\Scripts\python.exe tests/test_tiled_map.py

## 발판 배치

`발판` 오브젝트 레이어를 선택하고 `발판` 타일셋의 짧은 발판(32×16) 또는 긴 발판(64×16)을 **타일 삽입(Insert Tile)** 도구로 놓습니다. 기존 발판을 선택해 복사해도 됩니다. 오브젝트의 윗면이 실제 밟는 높이이고, 아래에서 점프할 때 통과합니다. 이동·가로 크기 조절 시 판정이 자동으로 따라갑니다. 별도 충돌 사각형은 추가하지 않습니다. `collisionHeight`는 원본 기준 판정 두께이며 기본 8픽셀입니다.


### 기존 발판과 규격이 달라 보일 때

발판은 일반 지형의 32×32 격자와 규격이 다릅니다. 짧은 발판은 **32×16**, 긴 발판은 **64×16**이며, 화면을 200%로 확대하면 각각 64×32, 128×32로 보입니다.

1. 오른쪽 **레이어 목록 → 발판** 오브젝트 레이어를 선택합니다.
2. **발판** 타일셋에서 짧은/긴 발판을 고릅니다.
3. **타일 삽입(Insert Tile)** 도구로 배치합니다. 새 지형 레이어의 스탬프 브러시는 사용하지 않습니다.
4. 크기를 변경했다면 오브젝트 속성의 너비/높이를 짧은 발판 **32/16**, 긴 발판 **64/16**으로 맞춥니다.

32×32 타일 레이어에 스탬프로 찍으면 높이 16인 그림이 셀 아래쪽에 놓여 위쪽 16픽셀이 비어 보입니다. 파란 브러시 영역의 높이는 발판 이미지 높이가 아닙니다. 기존 발판과 높이를 정확히 맞출 때는 기존 발판을 복사한 뒤 위치만 옮기는 방법이 가장 간단합니다. 오브젝트의 Y는 **발판 바닥** 기준이므로 실제 윗면은 `Y - 16`입니다.
