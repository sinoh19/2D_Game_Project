# Tiled로 맵 만들기

## 열기와 실행

1. 게임 폴더의 **open_map.cmd**를 실행합니다. 준비된 Tiled 편집기에서 현재 맵과 팔레트를 엽니다. 편집기가 없는 PC에서는 공식 배포를 `.tools`에 준비합니다.
2. 게임은 **run_game.cmd**로 실행합니다. 오른쪽 위 **디버그: 인게임**으로 바로 진입할 수 있습니다.
3. Tiled에서 수정한 뒤 **Ctrl+S**로 저장하고, 실행 중인 게임에서 **F6**을 누릅니다. 위치와 열린 문 상태를 유지하며 맵을 다시 읽습니다. 잘못된 맵은 기존 화면을 유지하고 오류를 표시합니다.

기본 편집 파일은 `maps/dungeon_01.tmj`, 편집기 프로젝트는 `maps/mercenary.tiled-project`입니다. 자체 형식 `assets/dungeon/dungeon_01.json`은 에셋·애니메이션 라이브러리와 과거 맵 보관용이며, 현재 배치는 `.tmj`에서 읽습니다.

## 타일 칠하기

오른쪽 타일셋에서 **동굴 지형 32px**를 고른 뒤, 레이어에서 **새 지형 (자동 충돌)**을 선택합니다. 스탬프 브러시로 칠하고 지우개로 지웁니다. 이 레이어에 새로 놓은 바닥·벽·천장은 자동 충돌을 사용합니다. 계단 반쪽 타일 두 개는 대각선 경사 판정을 갖고 있어 한 쌍으로 놓으면 64×32 경사가 됩니다. 자동 충돌 경사 타일은 수평 뒤집기만 지원합니다.

완성된 팔레트에는 바닥, 내부 채움, 천장 3종, 상승/하강 계단 4개, 좌우 벽과 하단 모서리가 들어 있습니다. 이미지 생성 도구로 그리는 과정 없이 준비된 타일을 선택해 배치하면 됩니다.

## 기존 맵 레이어

| 레이어 | 편집 방법 |
|---|---|
| 배경 이미지 | 큰 던전 이미지 한 장. 기본 잠금. 파일을 바꾸면 게임에서 읽고 맵 너비에 맞춰 패럴랙스를 계산 |
| 횃불·갑옷 | 오브젝트 선택 도구로 이동·복사. 가로세로 비율 유지. 게임에서는 불꽃 애니메이션 재생 |
| 기존 지형 32px | 일반 격자의 기존 타일. 브러시·지우개로 수정 |
| 기존 지형 16px 보정 | 원래 16픽셀 어긋난 위치의 타일을 보존하는 레이어. 격자 기준점이 16픽셀 이동 |
| 기존 세밀 배치 | 부분 너비 바닥 등 7개 타일 오브젝트. 선택해서 이동·크기 조절 |
| 발판 | 짧은/긴 발판을 선택·이동·복사. 그림과 위에서만 밟는 판정이 함께 이동 |
| 새 지형 (자동 충돌) | 새로 칠할 때 권장. 타일 자체의 충돌 자동 사용 |
| 기존 충돌·발판 | 원래 맵의 사각 충돌. 눈 아이콘을 켜면 붉은 사각형으로 편집 가능 |
| 대각선 경사면 | 원래 두 경사면의 선 끝점을 이동. 눈 아이콘을 켜서 편집 |
| 좌우 철문 통로 | 통로 전체를 선택해서 이동. 기존 철창·벽·천장이 함께 이동 |
| 시작 위치 | 노란 시작점. 캐릭터의 발 좌표 |

**기존 지형 레이어와 기존 충돌은 원래 배치를 보존하기 위해 분리했습니다.** 기존 바닥을 옮기거나 지우면 해당 사각 충돌·경사 선도 같이 수정해야 합니다. 기존 지형 레이어의 `autoCollision`을 무작정 켜면 원래 충돌과 중복됩니다. 새 맵은 아래의 자동 충돌 템플릿으로 만드는 편이 간단합니다.

충돌 레이어의 눈 아이콘은 편집기 안내선 표시용입니다. 레이어를 숨겨도 충돌은 게임에 적용됩니다. 실제로 끄려면 해당 레이어나 오브젝트에 bool 속성 `enabled=false`를 지정합니다.

## 장식과 철문 넣기

**장식·통로** 타일셋의 횃불·갑옷·좌측 통로·우측 통로를 오브젝트 레이어에서 타일 오브젝트로 삽입합니다. 짧은/긴 발판은 별도의 **발판** 타일셋에 있습니다. 기존 오브젝트를 복사해서 놓아도 됩니다. 시작 위치와 경사 같은 판정은 타일이 아닌 점/선 오브젝트입니다.

- `Torch`, `Armor`: 게임에서 원래 소품으로 표시하며 횃불이 움직입니다. 회전·뒤집기 없이 가로세로 비율을 유지하세요.
- `Passage`: 폭은 32의 배수로 유지합니다. `side`는 left/right, `openingHeight`는 입구 높이, `gateWidth`는 철문 폭입니다. 높이는 오브젝트 바닥에서 위로 계산합니다.
- 기존 철문을 복사했다면 `gateId`를 새 고유 값으로 바꾸거나 비우세요. 비우면 Tiled 오브젝트 ID를 사용합니다. ID가 중복되면 오류로 알려줍니다.
- `Spawn`: 시작점은 정확히 하나 있어야 합니다.
- `Solid`: 사각형 전체가 막힙니다. `Platform`: 아래에서 점프로 통과할 수 있는 발판입니다.
- `Slope`: 폴리라인으로 대각선을 그리고 클래스를 지정합니다. 수직 선과 오브젝트 회전 대신 끝점을 움직여 편집합니다.

현재 통로는 철문 개방과 통과까지 연결되어 있으며, 다른 맵으로의 전환은 아직 구현하지 않았습니다.

## 새 맵 만들기

`maps/new_level_template.tmj`를 Tiled에서 열고 **다른 이름으로 저장**합니다. 이 템플릿은 자동 충돌 바닥과 시작점만 있는 빈 맵입니다. 기본 맵의 수동 충돌을 지울 필요가 없습니다.

새 맵 실행 예:

```powershell
.\run_game.cmd --map maps/my_dungeon.tmj
```

기본 실행 맵을 영구적으로 바꾸려면 `game/config.py`의 `DEFAULT_TILED_MAP` 경로를 바꿉니다. 기본 게임 화면은 640×360, 타일은 32×32입니다. 맵 너비는 Tiled의 맵 크기 변경으로 늘릴 수 있습니다. 세로 스크롤은 아직 없으므로 `worldHeight=360`을 유지하세요. 타일 행은 12행(384픽셀)이지만 하단 24픽셀은 화면 밖입니다.

맵은 고정 크기 직교 맵, JSON `.tmj`, 외부 JSON 타일셋 `.tsj`를 사용합니다. CSV 배열 또는 비압축/base64 zlib/gzip 데이터를 읽습니다. 무한 맵과 zstd 압축은 사용하지 마세요. 원본 이미지와 타일셋 파일도 같이 Git으로 관리합니다.

## 발판 배치

`발판` 오브젝트 레이어를 선택하고 `발판` 타일셋의 짧은 발판(32×16) 또는 긴 발판(64×16)을 **타일 삽입(Insert Tile)** 도구로 놓습니다. 기존 발판을 선택해 복사해도 됩니다. 오브젝트의 윗면이 실제 밟는 높이이고, 아래에서 점프할 때 통과합니다. 이동·가로 크기 조절 시 판정이 자동으로 따라갑니다. 별도 충돌 사각형은 추가하지 않습니다. `collisionHeight`는 원본 기준 판정 두께이며 기본 8픽셀입니다.


### 기존 발판과 규격이 달라 보일 때

발판은 일반 지형의 32×32 격자와 규격이 다릅니다. 짧은 발판은 **32×16**, 긴 발판은 **64×16**이며, 화면을 200%로 확대하면 각각 64×32, 128×32로 보입니다.

1. 오른쪽 **레이어 목록 → 발판** 오브젝트 레이어를 선택합니다.
2. **발판** 타일셋에서 짧은/긴 발판을 고릅니다.
3. **타일 삽입(Insert Tile)** 도구로 배치합니다. 새 지형 레이어의 스탬프 브러시는 사용하지 않습니다.
4. 크기를 변경했다면 오브젝트 속성의 너비/높이를 짧은 발판 **32/16**, 긴 발판 **64/16**으로 맞춥니다.

32×32 타일 레이어에 스탬프로 찍으면 높이 16인 그림이 셀 아래쪽에 놓여 위쪽 16픽셀이 비어 보입니다. 파란 브러시 영역의 높이는 발판 이미지 높이가 아닙니다. 기존 발판과 높이를 정확히 맞출 때는 기존 발판을 복사한 뒤 위치만 옮기는 방법이 가장 간단합니다. 오브젝트의 Y는 **발판 바닥** 기준이므로 실제 윗면은 `Y - 16`입니다.


### 뭉툭한 끝부분 발판

`발판` 팔레트에 왼쪽 끝, 오른쪽 끝, 양끝 둥근 짧은/긴 발판이 추가되어 있습니다. 긴 발판을 연결할 때는 **왼쪽 끝(32×16) → 기존 짧은/긴 발판 → 오른쪽 끝(32×16)** 순서로 배치합니다. 끝부분의 안쪽 면은 기존 타일과 같은 원본 픽셀을 사용하며, 바깥쪽 모서리만 투명하게 깎았습니다. 짧게 독립 배치할 때는 양끝 둥근 버전을 사용하세요.

기존과 동일하게 `발판` 오브젝트 레이어에서 타일 삽입 도구로 배치합니다. 그림 높이 16, 판정 두께 8을 유지합니다. Tiled에서 팔레트가 갱신되지 않으면 맵을 저장한 뒤 다시 여세요. 기존 사각형 발판과 사용자 맵 배치는 그대로 유지됩니다.


### 갑옷의 바닥 정렬

갑옷은 원래 이미지 아래의 투명 여백 2픽셀을 보정한 배치용 이미지를 사용합니다. 오브젝트 크기 38×76과 기존 좌표는 유지되며, 발끝이 오브젝트 바닥(Y)에 맞습니다. `groundOffset=2`가 게임에서도 같은 보정을 적용합니다. Ctrl 스냅으로 갑옷의 Y를 바닥 윗면에 맞추면 됩니다. 바닥 타일의 아랫변이 아닌 윗변에 맞추세요.


### 천장 샹들리에

외부 타일셋 `maps/tilesets/ceiling-decorations.tsj`를 맵에 추가하면 **천장 장식** 팔레트가 표시됩니다. 기존 오브젝트 레이어(예: 횃불·갑옷)를 선택하고 타일 삽입 도구로 배치합니다. 샹들리에는 48×64이며 **윗변이 기준점**입니다. Ctrl 스냅으로 Y를 천장 아랫면에 맞추면 쇠사슬이 바로 매달립니다. 일반 바닥 소품처럼 Y에서 높이를 빼지 않습니다. 장식이므로 충돌은 없습니다. 게임에서는 촛불 세 개가 서로 다른 타이밍으로 일렁입니다(6프레임, 8fps). 쇠사슬·본체·양초는 고정입니다. Tiled에는 정지 미리보기가 표시되며, 실행 중 F6으로 다시 읽으면 기존 샹들리에에도 적용됩니다. `flameAnimation=false`로 끌 수 있습니다. 이동/비율 유지 크기 조절은 가능하고 회전은 지원하지 않습니다.


### 불 주변의 주황빛

기존 횃불과 샹들리에는 게임에서 은은한 주황빛으로 주변 배경·소품·캐릭터를 밝힙니다. 중심이 밝고 가장자리로 갈수록 자연스럽게 사라지며 밝기가 약하게 일렁입니다. 장식을 옮기거나 크기를 바꾸면 빛도 따라갑니다. 샹들리에의 `warmLight=false` 속성으로 빛만 끌 수 있습니다. 벽에 의한 그림자/빛 차단은 현재 적용하지 않습니다. Tiled에서는 정지 이미지로 보이며 게임 재실행 또는 F6으로 확인합니다.


샹들리에는 횃불과 도트 밀도를 맞추기 위해 24×32 작업 해상도를 2배 확대한 48×64 이미지입니다. 원래 철제 촛대와 속이 빈 쇠사슬 고리 형태, 배치 크기와 천장 기준점을 유지하고, 횃불과 같은 공용 팔레트·2×2 픽셀 단위로 맞췄습니다. 기존 불꽃 애니메이션과 주황빛도 새 불꽃 위치를 따릅니다.


철문도 원래 24×104 크기와 철창 네 줄을 유지하면서 공용 금속 팔레트·2×2 픽셀 단위로 정리했습니다. Tiled 통로 이미지와 게임 철문이 같은 도트 밀도를 사용합니다. 개방 속도·높이·충돌 판정은 기존과 같습니다.


## 추가 가구와 목재 소품

**가구·소품**, **목재 구조물** 팔레트에 사진 기반 소품 10종이 있습니다. 오브젝트 레이어에서 타일 삽입 도구로 놓습니다. 크기와 목재 구조 설명은 [DUNGEON_PROPS.md](DUNGEON_PROPS.md)를 참고하세요. 현재 장식 배치용이며 자동 충돌은 없습니다.


## 휘장을 걸 배경 기둥

**배경 돌기둥** 팔레트를 **배경 기둥** 레이어에서 배치합니다. 큰 배경 위·소품 아래에 그려집니다. 완성형과 위/중간/아래 모듈 사용법은 [BANNER_PILLARS.md](BANNER_PILLARS.md)를 참고하세요.


기본 바닥은 반복되는 윗면 홈을 줄여 계단 끝과 매끄럽게 이어지도록 조정했습니다. 원래 돌 몸체는 보존하고 위쪽6픽셀만 수정했으며, 지형 크기·충돌 높이·경사 판정은 그대로입니다. 기존 Floor 타일에도 자동으로 적용됩니다.


## 구멍의 둥근 윗끝 만들기

**동굴 지형 32px** 팔레트 아래에서 두 번째 줄의 마지막 두 칸에 **구멍 왼쪽 윗끝**, **구멍 오른쪽 윗끝**이 있습니다. 각각 구멍 왼편의 바닥 끝(오른쪽 모서리가 둥금), 구멍 오른편의 바닥 끝(왼쪽 모서리가 둥금)에 놓습니다. 크기는32×32이며 기존 바닥·세로 벽·아래 모서리와 연결됩니다.

**새 지형 (자동 충돌)** 타일 레이어에서 스탬프 브러시로 배치하세요. 깎인 투명 부분을 제외한 돌 모양에 맞춰 충돌이 적용됩니다. 구멍 안쪽의 기존 바닥/채움 타일은 지워야 합니다. 기존 수동 충돌 레이어에 사각형이 남아 있다면 해당 부분도 따로 수정해야 실제로 구멍이 열립니다. 기존 지형과 맵 배치는 자동으로 지우거나 바꾸지 않습니다.


## 구멍 아래쪽의 연결

**동굴 지형 32px** 팔레트 맨 아래 줄의 **하단 평면 연결**, **하단 왼쪽 둥근 연결**, **하단 오른쪽 둥근 연결**은 각각32×32입니다. 왼쪽 둥근 연결(돌이 오른쪽에 있음) → 평면 연결 여러 개 → 오른쪽 둥근 연결(돌이 왼쪽에 있음) 순서로 지형의 아래 끝을 만들 수 있습니다. 가운데 그림은 바닥 윗면이 아닌 지형의 밑면입니다.

**새 지형 (자동 충돌)** 레이어에서 스탬프 브러시로 배치합니다. 모서리의 투명한 부분에는 충돌이 없습니다. 기존 세로 벽 타일의 아래에 둥근 조각을 이어 놓고, 그 바깥쪽으로 평면 밑면을 이어가세요. 기존 타일이나 맵 배치는 자동으로 교체하지 않습니다.

하단 3종은 동굴 지형 팔레트에 통합했습니다. 예전 구멍 하단 연결 팔레트로 배치했던 타일도 같은 모습으로 유지됩니다.

하단 연결 타일은 상단 끝 타일에 대응하는 작은 둥근 모서리와 연속된 회색 돌 테두리를 사용합니다. 기존 큰 하단 곡선을 재사용한 초기 버전의 턱과 테두리 끊김을 수정했습니다.


하단 연결 3종은 **동굴 지형 32px**의 맨 아래 줄에 통합되어 있습니다. 왼쪽부터 하단 평면 연결, 하단 왼쪽 둥근 연결, 하단 오른쪽 둥근 연결 순서입니다. 기존 상단 모서리 2종은 그 바로 윗줄 오른쪽에 있습니다.


## 계단과 평지의 연결

**계단·바닥 연결 32px** 팔레트에는 32×32 전용 연결 타일 2종이 있습니다. **왼쪽 끝**은 왼쪽에서 올라오는 계단 바로 오른쪽 평지 첫 칸에, **오른쪽 끝**은 오른쪽으로 내려가는 계단 바로 왼쪽 평지 마지막 칸에 놓습니다. 순서는 `오르막 계단 → 왼쪽 연결 → 일반 Floor → 오른쪽 연결 → 내리막 계단`입니다.

현재 맵의 계단 양끝에 적용하고 새 맵 템플릿에도 팔레트를 추가했습니다. 기존 계단의 경사 판정과 바닥 높이는 유지합니다. 새로 배치할 때는 **새 지형 (자동 충돌)** 레이어를 사용하세요.

## 바닥 뒤의 나무 다리 배치

나무 다리는 **배경 구조물** 오브젝트 레이어에서 **타일 오브젝트 삽입**으로 배치하세요. 이 레이어는 기존 지형32px·16px보정과 새 지형보다 뒤에 그려져 다리 양끝이 바닥에 가려집니다. 다리의 기본 크기는128×32이며, 3칸(96px) 구멍 양쪽에16px씩 겹치게 놓으면 됩니다. 오브젝트의 Y는 아래쪽 기준이므로 그림 윗면이288이면 Y는320입니다. 현재 다리는 기존 타일 레이어에서 이 레이어로 옮겼습니다.

## 다리 양끝 연결부

받침목이 포함된 **나무 다리(128×32)**는 **배경 구조물** 레이어에 놓습니다. **다리 연결부** 팔레트의 왼쪽·오른쪽(각32×32)은 **지형 앞 연결부** 오브젝트 레이어에서 타일 오브젝트로 얹으세요. 두 연결부에는 돌 덮개와 접촉 그림자가 포함됩니다.

다리의 좌표가 X,Y라면 왼쪽 연결부는 **X,Y**, 오른쪽은 **X+96,Y**입니다. 크기는 원본대로 유지하세요. 현재 다리에도 적용했으며, 새 맵 템플릿에도 레이어와 팔레트를 추가했습니다. 다리를 이동할 때는 본체와 연결부 두 개를 함께 선택해 이동하세요. 연결부는 장식으로 충돌을 추가하지 않습니다.


### 단순 도트 다리

현재 나무 다리는128×32, 4색·2×2픽셀 단위로 정리했습니다. **배경 구조물** 레이어에 다리 본체만 놓으세요. 3칸 구멍 양쪽으로16px씩 겹치면 상판과 대각 지지대 끝이 벽에 묻혀 깔끔하게 이어집니다. 현재 맵에서 별도 돌 덮개·접촉 그림자는 제거했으므로 위의 연결부 추가 배치는 선택 사항입니다. 기존 연결부 팔레트는 호환용으로 남겨둡니다.

## 지형 내부 자동 음영

게임은 동굴 지형·계단 연결·발판의 실제 불투명한 모양을 합친 뒤, 노출된 표면에서 안쪽으로 멀어질수록 어둡게 표시합니다. 기본값은 표면6px를 유지하고 그 안쪽40px에 걸쳐 거의 검게 전환합니다. 타일 사이를 별도 경계로 취급하지 않으며, 구멍·투명 모서리는 빈 공간으로 처리합니다. 기둥·가구·캐릭터·목재 구조물은 제외합니다. 철문 주변 암벽도 같은 계산에 포함하되 철문 자체는 제외합니다.

이 효과는 원본 PNG나 충돌을 수정하지 않는 게임 렌더링 효과입니다. Tiled 편집기에는 원본색으로 보이며, 게임의 **F6 맵 새로고침**으로 음영도 다시 계산됩니다. 맵 사용자 속성 **terrainInteriorShading (bool)**을 false로 설정하면 끌 수 있고, **terrainInteriorDepth (float)**로 어둡게 전환되는 거리(px, 기본40)를 조절할 수 있습니다. 새 사용자 팔레트를 포함하려면 해당 타일셋에 **terrainInterior (bool)=true** 속성을 추가하세요. 특정 타일에 같은 속성을 false로 지정하면 제외할 수 있습니다.
음영 내부의 뾰족한 끝은 대각선 거리 계산과8px 반경의 원형 경계 다듬기로 완화합니다. 좁게 솟은 검은 부분만 줄이고 표면·구멍으로 음영을 퍼뜨리지 않습니다. 이 계산 역시 맵을 읽거나 F6으로 다시 불러올 때 한 번 수행합니다.

## 슬라임 배치와 순찰

- `몬스터` 오브젝트 레이어에서 `몬스터` 팔레트의 슬라임을 타일 오브젝트로 배치합니다. 기본 크기는 32×32이며, 오브젝트 아래쪽 Y를 바닥 윗면에 맞춥니다.
- 기본 맵에는 계단 다음 평지에 한 마리가 배치되어 있습니다. 중심 X 720, 발 Y 288, 순찰 중심 범위 X 640~800입니다.
- `patrolLeft` / `patrolRight`: 왕복할 중심 X 좌표. 두 값 사이에 슬라임 시작 중심이 있어야 합니다. 배치를 멀리 옮길 때 범위도 함께 수정하세요.
- 새로 배치한 슬라임은 기본적으로 시작 위치 좌우 `patrolRadius`(80px) 범위를 사용합니다. 절대 범위를 지정하려면 위 두 속성을 float 형식으로 추가하세요.
- `speed`: 공중 동작 중 이동 속도(px/s), 기본 48. 땅에 붙어 눌리는 프레임에는 이동하지 않습니다. `direction`: `left` 또는 `right`; 속성을 생략하면 수평 뒤집기로 초기 방향을 정할 수 있습니다.
- 벽이나 낭떠러지 앞에서 돌아서며, 8px 이하 높이 변화와 대각선 경사면을 따라갑니다. 바닥 위에 배치하세요. 접촉하거나 C키 공격에 맞으면 임시 근접 전투 화면으로 전환됩니다.
- 저장 후 게임에서 F6으로 새로고침하면 배치와 순찰 범위를 다시 읽습니다. 순찰 상태는 새로고침/스테이지 재진입 시 초기화됩니다.


## 근접 전투 진입 확인

- 플레이어와 슬라임의 기본 체력은 각각 100, 첫 타격 피해는 10입니다.
- 슬라임 몸체에 닿으면 플레이어만 10 피해를 받고 전환됩니다. C키 공격의 유효 타격 구간에 정면의 슬라임을 맞히면 슬라임만 10 피해를 받고 전환됩니다. 헛스윙·뒤쪽·벽 너머에는 공격 피해가 적용되지 않습니다.
- 전환된 장면은 검은 배경에 `근접 전투`, 진입 원인과 양쪽 HP만 표시합니다. 피해는 한 번만 적용되고 필드 이동·순찰이 멈춥니다. 아직 턴제 공방은 구현하지 않았습니다.
- ESC로 저장 후 메인으로 돌아갑니다. 현재 저장은 기존 위치·철문 상태까지만 유지하며, 체력은 필드 재진입/F6에서 100으로 초기화되는 검증 단계입니다.
