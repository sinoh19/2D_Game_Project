# 용병 일기 — Python + pico2d

귀족의 의뢰를 받은 용병이 던전을 탐험하는 2D 횡스크롤 게임입니다. 공격하거나 투사체에 맞으면 별도 턴제 전투로 전환하는 기획이며, 현재는 인트로·던전 탐험·캐릭터 조작·통로 철문까지 구현했습니다.

## 실행

Windows와 Python 3 환경에서 실행합니다. 현재 개발 환경은 Python 3.13, pico2d 1.3.7입니다.

```powershell
git clone https://github.com/sinoh19/2D_Game_Project.git
cd 2D_Game_Project
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
.\run_game.cmd
```

이미 받은 폴더에서는 `run_game.cmd`를 실행하면 됩니다. 필요한 가상환경이 없으면 설정을 시도합니다. VS Code에서 폴더 또는 `용병일기.code-workspace`를 열고 F5로 실행할 수도 있습니다.

가상환경과 개인 저장 데이터는 Git에 포함하지 않습니다. 새로 받은 PC에서는 `setup.ps1`로 환경을 만듭니다. 실행 시 Unity나 다른 드라이브의 원본 프로젝트가 필요하지 않습니다.

| 화면 | 조작 |

## 현재 구현

- 오두막·숲 애니메이션과 게임 시작 / 이어하기 / 설정 / 게임 종료 메뉴.
- 창문 줌인 → 암전 → 아이와 엄마의 대화 → 일기장 펼침 → 타일 뒤집기 → 던전 진입.
- 대기·이동·공격·점프 준비/상승/정점/낙하/착지 애니메이션.
- 가로 2560픽셀 던전, 카메라 추적, 발판·장애물 충돌.
- 계단 그림 아래의 충돌은 작은 사각형 대신 연속된 대각선 경사면 2개를 사용합니다. 경사를 오르내릴 때 반복 착지 딜레이가 없습니다.
- 큰 던전 배경 이미지 한 장이 지형 뒤에서 천천히 움직입니다. 동굴 바닥·암벽·천장과 통로 모서리를 별도 배치합니다.
- 캐릭터·횃불·갑옷은 동일한 2픽셀 격자와 제한된 색상으로 표시합니다. 원본 이미지와 애니메이션 타이밍은 보존합니다.
- 좌우 통로의 철문은 E를 누르면 약 1.52초 동안 기계음과 함께 위로 열립니다. 열린 뒤 지나갈 수 있고 열린 상태를 저장합니다.
- 게임 시작은 새 위치와 닫힌 문으로 시작하고, 이어하기는 저장된 위치와 문 상태를 복원합니다. 인트로를 취소하면 이전 저장은 유지합니다.
- 디버그 버튼으로 바로 진입하면 새 진행으로 시작합니다. 버튼은 인게임에서 숨깁니다.

적·투사체·턴제 전투·아이템·다음 맵 전환은 아직 구현하지 않았습니다.

## 화면·아트 기준

- 실제 렌더링은 **640×360**, 실행 창은 **1280×720**입니다. 완성된 화면을 최근접 보간으로 정수 2배 확대합니다.
- 지형의 기본 격자는 32×32입니다. 전체 화면과 개별 에셋 크기는 구분합니다.
- 캐릭터 기본 프레임은 56×56, 공격 프레임은 112×112, 실제 몸 높이는 약 46픽셀입니다.
- 원본과 사용하지 않는 과거 에셋은 보관하고, 지도에 지정된 파일을 사용합니다.

## 점검

```powershell
.\.venv\Scripts\python.exe main.py --self-check
```

실제 SDL 렌더링으로 메뉴·줌인·대화 입력·책/타일 전환·이동·저장·설정·종료를 점검합니다. 임시 저장을 사용하므로 개인 진행을 덮어쓰지 않습니다.

기획 PPT와 발표 영상도 저장소에 함께 보관합니다. 개발 변경은 작업 단위로 커밋하여 이 저장소에 업데이트합니다.

## 직접 맵 편집하기

`open_map.cmd`를 실행하면 Tiled에서 현재 맵을 엽니다. **새 지형 (자동 충돌)** 레이어를 선택해 타일을 칠하고 Ctrl+S로 저장한 뒤, 게임에서 **F6**을 누르면 반영됩니다. 장식·철문·시작점·경사면은 오브젝트로 이동할 수 있습니다. 처음 새 맵을 만들 때는 `maps/new_level_template.tmj`를 다른 이름으로 저장하세요.

기존 맵에는 원래 위치와 충돌을 보존하는 수동 레이어도 있으므로 [Tiled 사용 가이드](docs/TILED_GUIDE.md)를 먼저 참고하세요. 별도의 Tiled JSON 내보내기는 필요 없으며 `.tmj` 저장 파일을 게임이 직접 읽습니다. 편집기는 처음 실행 시 공식 배포를 프로젝트 `.tools/`에 준비하며 Git에는 포함하지 않습니다.
